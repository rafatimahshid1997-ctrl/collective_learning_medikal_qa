# collective_learning_medikal_qa
 Bu proje, Türkçe tıbbi soru-cevaplama için cosmos:T1-2B modelinin kolektif öğrenme yaklaşımıyla kendi yanıtlarını değerlendirme ve iyileştirme sürecini incelemektedir. Model, üç iterasyon boyunca LoRA tabanlı olarak eğitilmiş ve yanıt doğruluğu, güvenliği ve netliği analiz edilmiştir.
